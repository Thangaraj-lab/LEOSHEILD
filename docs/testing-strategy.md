# Testing and physical validation

Run `./scripts/run_tests.ps1 -q` for the automated suite. The fixtures are generated geometry with controlled texture and artificial marks. They check mechanics and carry no accuracy claim. The suite covers two-view progression, clean and marked candidate response, normalized EXIF coordinates, invalid formats and oversized content, resolution and lighting rules, attempt budget, expiry, evidence integrity and restart, bearer authentication, hardware fail-closed responses, and contract export compatibility.

The approved Windows test run returned **13 passed** in 3.28 seconds. Starlette emitted one deprecation warning about its HTTPX test adapter. The default app sandbox blocked Python's internal Windows loopback socket, so the successful run used approved local execution. Run `python -m tests.local_http_smoke` with the workspace interpreter to recheck real loopback HTTP with outbound connects blocked by a Python audit hook.

The port 8001 smoke run passed. The first fixture produced HOLD at one of two required regions. The second produced REVIEW at two of two regions and Laptop 1 served the original evidence bytes. The latest synthetic run measured 243 ms for decode and analysis and 399 ms for the scripted HTTP sequence, including client-side fixture generation. Physical capture and operator time remain unmeasured.

For the current two-view baseline, run `.venv/Scripts/python.exe -m scripts.benchmark <dataset.json>`. The dataset JSON contains `dataset_id`, `source` and `pieces`. Each piece contains a unique `piece_id`, a `label` of `normal`, `defective` or `critical`, and `front` and `back` image paths relative to the dataset directory. The runner reports screening by physical piece, required-view coverage, HOLD count and decode/analysis time. The recall denominator includes held defective pieces. It cannot establish localization accuracy, acquisition time or operator performance. Add `--publish` to make a physical replay report available through the API. Synthetic reports are excluded from the endpoint.
