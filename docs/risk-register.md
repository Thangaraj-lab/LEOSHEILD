# Open engineering risks

| Risk | Severity | Mitigation and open evidence |
|---|---|---|
| Incorrect LED voltage, polarity or current path | High | Verify markings, datasheets and protection inventory before any wiring approval |
| Defect misses or nuisance alerts | High | Preserve human approval and measure recall and false positives on representative labeled pieces |
| Incorrect operator view or lighting tag | High | Prompt by required view, reject exact duplicate bytes, and verify station synchronization before automation |
| Uncontrolled background, glare or material texture | High | Use controlled capture and calibrate profile thresholds on representative samples |
| LAN disclosure | High | Bind locally by default and restrict any token-protected HTTP demo to a trusted isolated LAN |
| Evidence file accumulation | Medium | Monitor free space and agree on local data retention before extended use |
| Interrupted evidence write | Medium | Expose only atomically published manifests and their referenced originals |
